## 8.6 git操作顺序
1. `init`→`add .`→`commit -m`
2. `checkout -b `→`checkout`→`log --oneline`→`diff`→`merge`
3. `reset --hard HEAD~1`
4. `add .`→`commit -m`→`push -u origin`
## git命令表格
 |命令|作用|什么时候用|
 |--|--|--|
 |`add .`|把当前目录加入暂存区|要把更改提交到存储库中时|
 |`init`|初始化当前项目|首次开启版本远程控制|
 |`commit -m`|将暂存区的修改提交到存储库中|要将修改内容保存到存储库|
 |`checkout -b `|创建新的分支|需要多次调试代码并且比较选出最优方案或许多人对代码操作|
 |`checkout`|切换分支|要从一个分支切换到另一个分支|
 |`log--oneline`|查看提交历史|需要具体查看提交的历史内容|
 |`diff`|代码内容对比|需要将两个分支中代码不同的地方找出比较|
 |`merge`|将分支合并|在分支中选择最优方案并把修改内容合并到主代码中|
 |`reset --hard HAED~1`|退回丢掉最后一次提交|需要去除最后一次提交内容|
 |`push -u origin`|将当前分支推送到存储库|创立了新的分支第一次推送入存储库|
 |`pull`|拉取存储库中的分支到当前代码|当前代码不是最新代码需要更新到与存储库中一致|
## 实际执行过的命令
```
git checkout main
git log --oneline
git diff main feature-blink
git merge feature-blink 
git reset --hard HEAD~1
```
